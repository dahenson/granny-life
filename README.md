# Granny Life Motif Generator

[Live Demo](https://brainofdane.com/granny-life)

This web app is inspired by and derived from the work of [mathgrrl](https://mathgrrl.com) and her
[granny life](https://www.grannylifecrochet.com/) project. I participated in the community build project, contributing
generations 228 and 1201. After participating, I became interested in the implementation, which led me to create the
web app.

This app was a learning project for me to see what can be done with Gleam and Lustre. In this project, I advanced
my understanding of Gleam, Lustre, embedded SVG, and CSS.

## Development

```sh
gleam test                     # Run the tests
gleam run -m lustre/dev start  # Run the app
gleam run -m lustre/dev build  # Build the app
```
